# 项目审查与整理

日期：2026-09-23。范围包括工作区现有 v2/v3 实现、插件与树内适配、运行时、
分析工具、配置模板、测试入口和项目文档。

## 已修复的问题

| 问题 | 当前行为与验证 |
| --- | --- |
| v3 仅插桩第一份源码，其他源文件漏采集 | 先链接全部 IR 再插桩；双文件测试获得预期两条事件 |
| 应用 `fa_*` 函数被当作运行时跳过 | 运行时内部函数改用 `__fa_runtime_*`，普通 fa_worker 回归已覆盖 |
| 函数配置错误可能回退为全部函数 | 省略/空数组明确为全部；类型或名称错误报错；v2/v3 都支持精确筛选 |
| v3 插桩后遗留 pointer/call 优化属性 | 共用 v2 的定义与调用点属性清理；IR verifier 和属性回归检查 |
| v2 应用非零退出和中断可能被当作成功 | 失败向上传递；中断返回 130，不承诺完整尾块 |
| LTO 的仅分析模式仍插桩和链接 | 只生成静态报告；同名源文件使用不同 bitcode 路径 |
| 模板在 JSON 与 Python 中重复并漂移 | 唯一 JSON 模板，显式全函数/全量默认值，移除无用占位输入和旧线程宏说明 |
| dry-run 要求实际产物且切入不存在目录 | 不依赖已构建插件，不写输出目录；v3 不支持的选项明确拒绝 |
| 旧 trace 或过期插件可能混入新运行 | 插件增量构建；采集前拒绝已有 trace 的目录；固定输出路径 |
| 完整性认证未检查无状态的线程事件 | 核对线程身份和计数、采样状态及全部静态报告，拒绝孤立事件 |
| 测试入口和文档与实现脱节 | 统一 shell 到 Python 入口；加入 --regressions，精简为当前配置/协议/使用文档 |

## 剩余限制

- 覆盖限于输入 IR 的函数体及支持的指令；v3 还受对象选择约束。外部库、内联汇编、
  后端 spill 和硬件预取不在认证范围。全函数不意味着硬件级全访存。
- 此轮没有执行需要外部输入或特定架构的全部 53 个 benchmark 变体，也未重新构建整个
  LLVM 静态树内集成。独立插件为本次实际验证路径。
- v3 的对象查找带锁且为线性表；访问图在每个窗口内两两枚举，复杂度 O(n²)。
  验证了功能语义，未完成大规模性能基准；全量插桩会扰动程序运行。
- v3 仅支持当前文档描述的全局/栈/显式 allocator 生命周期；异常展开、部分 munmap、
  自定义 allocator 隐式生命周期、异步信号插桩和初始化后 fork 不支持。
- 空 trace 不能认证完整；跨元素 range 不作为标量图节点。候选布局只投影地址，
  不改写程序、不预测 cache Hit/Miss 或性能提升。
